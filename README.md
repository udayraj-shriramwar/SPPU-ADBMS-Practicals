# SPPU ADBMS Practicals

This repository contains the practical programs and solutions for Advanced Database Management System (ADBMS) based on the SPPU practical problem statements.

The practicals are implemented using MongoDB and cover database creation, CRUD operations, queries, aggregation, indexing, MapReduce, and other MongoDB concepts.

## Practical List

| No. | Practical / Problem Statement |
|-----|-------------------------------|
| 1 | Create Tutorial collection and perform Insert, Update, Delete, Display and Search operations |
| 2 | Place an order for five products from a computer shop and prepare a bill |
| 3 | Implement aggregation and indexing using MongoDB |
| 4 | Execute queries on a student database to find highest, lowest, average marks and first-class students |
| 5 | Implement MapReduce operation for a supermarket |
| 6 | Create university database and perform teacher-related queries |
| 7 | Create library database and perform book and journal-related queries |
| 8 | Implement document insertion, removal and updating operations |
| 9 | Execute at least 10 queries demonstrating MongoDB querying techniques |
| 10 | Execute at least 10 queries using `$where`, cursors and database commands |
| 11 | Implement aggregation framework and different types of indexes |
| 12 | Create teacher database and implement any ten queries |
| 13 | Create restaurants collection and execute queries |
| 14 | Create author database and execute queries |
| 15 | Create Instructor collection and perform department, salary and status queries |
| 16 | Create Instructor collection and perform sorting, searching, limiting and `$addToSet` operations |
| 17 | Create Instructor collection and perform inclusion, exclusion, logical and substring queries |
| 18 | Create Instructor collection and perform city, department, salary and status queries |
| 19 | Create Instructor collection and perform delete, logical and salary-based queries |
| 20 | Create Instructor collection and perform salary, state, department and substring queries |
